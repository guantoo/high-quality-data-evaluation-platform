# 高质量数据评估平台操作流程与功能补全清单

更新时间：2026-08-25

## 一、平台主操作流程

1. 数据接入
   - 新建数据库、文件仓、SFTP 或 REST API 连接。
   - 验证连接可达性和最小权限。
   - 保存同步策略并执行首次同步。
2. 数据探查与盘点
   - 选择数据源和数据表。
   - 执行字段画像、完整度、唯一值和异常扫描。
   - 形成业务域目录、敏感等级和血缘关系。
3. 数据治理与标注
   - 创建治理项目并编排数据集、Recipe、标注、质检和输出节点。
   - 配置清洗、解析、对齐、标注和质量门禁。
   - 执行流程并查看节点日志、质量结果及血缘。
4. 高质量数据集生产
   - 生成清洗后的新版本。
   - 完成人工标注、复核与抽检。
   - 通过质量门禁后形成可交付数据集。
5. 数据集质量评估
   - 选择评估对象、评估标准和审查组件。
   - 执行评估任务并定位问题样本。
   - 生成质量报告和整改建议。
6. 模型开发
   - 选择基础模型、数据集版本和开发方式。
   - 执行微调、RAG、蒸馏或模型注册任务。
   - 查看日志、训练指标和产出版本。
7. 模型能力评测与交付
   - 创建能力、安全和性能评测任务。
   - 对比候选模型并执行发布门禁。
   - 交付模型或数据产品，保留版本、审计和追溯记录。
8. 平台管理与追溯
   - 在全局消息中统一处理质量、治理、模型和系统通知。
   - 通过审计日志追踪操作用户、业务对象、结果和来源地址。
   - 按角色配置模块只读、管理或无权限范围，并维护成员账号。
   - 自动保存本机业务状态，使用 JSON 备份完成迁移、恢复或重置。

## 二、功能补全优先级

| 阶段 | 当前状态 | 主要缺口 | 优先级 |
| --- | --- | --- | --- |
| 数据接入 | 页面完整，部分操作仅提示 | 连接验证、配置保存、同步进度、失败重试、进入探查 | P0 |
| 数据探查 | 已完成异常字段选择、问题样本保留和清洗任务创建 | 探查历史、跨表对比和结果导出 | P1 |
| 智能盘点 | 已具备资产与质量展示 | 目录展开、责任人分配、盘点报告下载 | P1 |
| 智能清洗 | 已具备规则开关、执行进度、不可变版本记录、结果对比和安全回滚 | 规则命中历史与审计导出 | P1 |
| 治理工作间 | 已具备差异化节点、标注、画布增删连线、失败定位和单节点重试 | 节点配置持久化与运行审计导出 | P1 |
| 治理算法 | 已具备创建、启停和市场安装 | 参数配置、版本发布、测试日志、项目引用 | P1 |
| 数据集评估 | 已具备配置向导、任务执行、问题整改复核闭环和报告导出 | 多次评估历史对比 | P1 |
| 模型开发 | 已具备参数配置、动态运行指标、检查点、产物版本和模型注册 | 运行失败恢复与版本审批 | P1 |
| 模型评测 | 已具备标准配置、动态执行、五项发布门禁、候选/基线对比和报告导出 | 多轮评测历史趋势与批量对比 | P1 |
| 平台管理 | 已具备全局消息、自动操作审计、角色权限控制、成员管理和本地备份恢复 | 多租户隔离、服务端集中审计与组织目录集成 | P2 |

## 三、逐项实施顺序

- [x] 工作间节点差异化及标注节点功能。
- [x] 数据接入闭环：创建、验证、配置、同步、进入探查。
- [x] 数据探查结果转清洗任务，并保留问题样本。
- [x] 智能清洗版本管理、结果对比和回滚。
- [x] 治理工作间节点增删、连线、运行失败与重试。
- [x] 数据集评估配置、问题闭环和报告导出。
- [x] 模型开发参数、运行指标和模型版本管理。
- [x] 模型评测标准、门禁判定和对比报告。
- [x] 全局消息、审计日志、权限控制和本地持久化。

## 四、完成标准

每项功能只有同时满足以下条件才标记完成：

- 入口可发现，操作路径连续。
- 表单可编辑并有必要校验。
- 执行过程有状态、进度、成功或失败反馈。
- 执行结果会更新页面数据，而不只是显示提示消息。
- 下一业务步骤可直接进入。
- 刷新或切换页面后的保留策略明确。
- 关键行为有自动测试覆盖。
